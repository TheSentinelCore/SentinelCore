# Universal Dispels

## Overview

The **Universal Dispels** module is an optional sub-plugin of the **Universal Utility** suite. You can install it from the [Marketplace](https://project-sylvanas.net/panel/plugins/detail/109). Once enabled, it becomes accessible under:

> **Main Menu -> Universal Utility -> Universal Dispels**

This plugin automatically detects and removes harmful debuffs in **PvP and PvE** based on pre-configured logic.

![](../../images/1748245693985HGMG-universal_utility_preview.png)

### 1 - Core Settings

- **Priority Filter** Controls how aggressively the plugin prioritizes dispels (Low / Medium / High)

- **Combat Mode** Can run in **PvP only**, **PvE only**, or **Both**

- **Humanizer Preset** Simulates human-like reaction time (Slow / Medium / Fast)

- **Allow Drawings** Toggles visual feedback for dispel events in-game.

### Built-in Spell Database

Works out of the box using a curated list of dangerous debuffs per class and encounter type. We encourage users to report missing or misclassified debuffs for refinement.

> **Tip**
> 
> Don't waste time looking for who needs a dispel—Universal Dispels does it instantly and intelligently.
