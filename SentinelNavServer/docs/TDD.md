## 1. Introduction

### 1.1 Purpose

This document describes the technical design for AmeisenNav-RS, a Rust-based HTTP navigation mesh server. It covers the FFI binding strategy, safe wrapper implementation, file format handling, and HTTP service architecture.

### 1.2 Scope

This design covers:
- FFI bindings to Recast/Detour C++ library
- Safe Rust wrapper layer
- TrinityCore mmap file format parsing
- HTTP service with Axum
- Path smoothing algorithms
- Thread safety and concurrency model

### 1.3 Design Goals

1. **Memory Safety**: Leverage Rust's ownership model while safely wrapping C++ code
2. **Performance**: Match or exceed AmeisenNavigation C++ performance
3. **Simplicity**: Simple HTTP API compatible with Lua clients
4. **Maintainability**: Clear crate boundaries and separation of concerns

## 2. FFI Binding Strategy

### 2.1 Three-Layer Architecture

The FFI binding follows a three-layer architecture to safely bridge Rust and C++:

```
┌─────────────────────────────────────────────────┐
│ Layer 3: Safe Rust Wrappers (detour crate)      │
│   - NavMesh, NavMeshQuery, QueryFilter          │
│   - RAII (Drop trait implementations)           │
│   - Idiomatic Rust API                          │
├─────────────────────────────────────────────────┤
│ Layer 2: Raw FFI Bindings (detour-sys crate)    │
│   - Generated by bindgen                        │
│   - Unsafe function declarations                │
│   - Opaque type pointers                        │
├─────────────────────────────────────────────────┤
│ Layer 1: C Wrapper Functions (wrapper.cpp)      │
│   - wrapper_dtNavMesh_addTile()                 │
│   - wrapper_dtNavMeshQuery_findPath()           │
│   - Calls C++ class methods internally          │
├─────────────────────────────────────────────────┤
│ Recast/Detour C++ Library                       │
│   - dtNavMesh, dtNavMeshQuery classes           │
│   - Compiled as static library via cc crate     │
└─────────────────────────────────────────────────┘
```

### 2.2 Why C Wrapper Functions?

Bindgen cannot directly generate bindings to C++ class methods. The standard solution is to create C wrapper functions that call the C++ methods:

```cpp
// C++ class method - cannot bind directly
dtStatus dtNavMesh::addTile(unsigned char* data, int dataSize, ...);

// C wrapper function - bindgen can bind this
extern "C" dtStatus wrapper_dtNavMesh_addTile(
    dtNavMesh* mesh, 
    unsigned char* data, 
    int dataSize, 
    ...
) {
    return mesh->addTile(data, dataSize, ...);
}
```

### 2.3 Bindgen Configuration

The `build.rs` file configures bindgen to generate minimal, focused bindings:

```rust
// build.rs
fn main() {
    // Compile Detour C++ sources
    cc::Build::new()
        .cpp(true)
        .include("recastnavigation/Detour/Include")
        .files(&[
            "recastnavigation/Detour/Source/DetourNavMesh.cpp",
            "recastnavigation/Detour/Source/DetourNavMeshQuery.cpp",
            // ... other sources
        ])
        .compile("detour");

    // Compile C wrapper
    cc::Build::new()
        .cpp(true)
        .include("recastnavigation/Detour/Include")
        .file("wrapper.cpp")
        .compile("detour_wrapper");

    // Generate bindings
    let bindings = bindgen::Builder::default()
        .header("wrapper.h")
        .clang_arg("-I./recastnavigation/Detour/Include")
        // Only bind wrapper functions
        .allowlist_function("wrapper_.*")
        // Opaque types for C++ classes
        .opaque_type("dtNavMesh")
        .opaque_type("dtNavMeshQuery")
        .opaque_type("dtQueryFilter")
        // Bind necessary structs
        .allowlist_type("dtNavMeshParams")
        .allowlist_type("dtStatus")
        .generate()
        .expect("Failed to generate bindings");

    bindings
        .write_to_file(PathBuf::from(env::var("OUT_DIR").unwrap()).join("bindings.rs"))
        .expect("Failed to write bindings");
}
```

## 3. Safe Rust Wrapper Design

### 3.1 NavMesh Wrapper

The NavMesh wrapper provides safe, idiomatic access to dtNavMesh:

```rust
pub struct NavMesh {
    ptr: NonNull<ffi::dtNavMesh>,
}

impl NavMesh {
    /// Create a new NavMesh from parameters
    pub fn new(params: &NavMeshParams) -> Result<Self, DetourError> {
        unsafe {
            let ptr = ffi::wrapper_dtAllocNavMesh();
            if ptr.is_null() {
                return Err(DetourError::AllocationFailed);
            }

            let status = ffi::wrapper_dtNavMesh_init(ptr, params.as_raw());
            if status_failed(status) {
                ffi::wrapper_dtFreeNavMesh(ptr);
                return Err(DetourError::from_status(status));
            }

            Ok(Self { ptr: NonNull::new_unchecked(ptr) })
        }
    }

    /// Add a tile to the navmesh
    /// 
    /// # Memory Ownership
    /// If `free_data` is true, the navmesh takes ownership of the data
    /// and will free it when the tile is removed. The data must have
    /// been allocated with Box::into_raw().
    pub fn add_tile(
        &self,
        data: TileData,
        last_ref: Option<TileRef>,
    ) -> Result<TileRef, DetourError> {
        let (ptr, len, flags) = match data {
            TileData::Owned(boxed) => {
                let len = boxed.len();
                let ptr = Box::into_raw(boxed) as *mut u8;
                (ptr, len, DT_TILE_FREE_DATA)
            }
            TileData::Borrowed(slice) => {
                // Copy data since Detour won't own it
                let boxed = slice.to_vec().into_boxed_slice();
                let len = boxed.len();
                let ptr = Box::into_raw(boxed) as *mut u8;
                (ptr, len, DT_TILE_FREE_DATA)
            }
        };

        let mut result: ffi::dtTileRef = 0;
        let status = unsafe {
            ffi::wrapper_dtNavMesh_addTile(
                self.ptr.as_ptr(),
                ptr,
                len as i32,
                flags,
                last_ref.unwrap_or(0),
                &mut result,
            )
        };

        if status_failed(status) {
            // Reclaim memory on failure
            unsafe { drop(Box::from_raw(ptr)); }
            return Err(DetourError::from_status(status));
        }

        Ok(result)
    }

    pub fn params(&self) -> &NavMeshParams {
        unsafe {
            let raw = ffi::wrapper_dtNavMesh_getParams(self.ptr.as_ptr());
            NavMeshParams::from_raw(raw)
        }
    }
}

// NavMesh is Send + Sync because it's read-only after initialization
unsafe impl Send for NavMesh {}
unsafe impl Sync for NavMesh {}

impl Drop for NavMesh {
    fn drop(&mut self) {
        unsafe {
            ffi::wrapper_dtFreeNavMesh(self.ptr.as_ptr());
        }
    }
}
```

### 3.2 NavMeshQuery Wrapper

The NavMeshQuery wrapper handles the non-thread-safe query object:

```rust
pub struct NavMeshQuery {
    ptr: NonNull<ffi::dtNavMeshQuery>,
    // Keep reference to NavMesh to ensure it outlives query
    _mesh: Arc<NavMesh>,
}

impl NavMeshQuery {
    /// Create a new query for the given navmesh
    pub fn new(mesh: Arc<NavMesh>, max_nodes: u32) -> Result<Self, DetourError> {
        unsafe {
            let ptr = ffi::wrapper_dtAllocNavMeshQuery();
            if ptr.is_null() {
                return Err(DetourError::AllocationFailed);
            }

            let status = ffi::wrapper_dtNavMeshQuery_init(
                ptr,
                mesh.ptr.as_ptr(),
                max_nodes as i32,
            );

            if status_failed(status) {
                ffi::wrapper_dtFreeNavMeshQuery(ptr);
                return Err(DetourError::from_status(status));
            }

            Ok(Self {
                ptr: NonNull::new_unchecked(ptr),
                _mesh: mesh,
            })
        }
    }

    /// Find path between two points
    pub fn find_path(
        &self,
        start: Vec3,
        end: Vec3,
        filter: &QueryFilter,
    ) -> Result<PathResult, DetourError> {
        const MAX_POLYS: usize = 256;
        const MAX_PATH: usize = 2048;
        
        let half_extents = [2.0f32, 4.0, 2.0];
        
        // Find start and end polygons
        let mut start_ref: ffi::dtPolyRef = 0;
        let mut end_ref: ffi::dtPolyRef = 0;
        let mut start_pt = [0.0f32; 3];
        let mut end_pt = [0.0f32; 3];

        unsafe {
            let status = ffi::wrapper_dtNavMeshQuery_findNearestPoly(
                self.ptr.as_ptr(),
                start.as_ptr(),
                half_extents.as_ptr(),
                filter.as_raw(),
                &mut start_ref,
                start_pt.as_mut_ptr(),
            );
            if status_failed(status) {
                return Err(DetourError::StartNotFound);
            }

            let status = ffi::wrapper_dtNavMeshQuery_findNearestPoly(
                self.ptr.as_ptr(),
                end.as_ptr(),
                half_extents.as_ptr(),
                filter.as_raw(),
                &mut end_ref,
                end_pt.as_mut_ptr(),
            );
            if status_failed(status) {
                return Err(DetourError::EndNotFound);
            }
        }

        // Find polygon path
        let mut poly_path = vec![0 as ffi::dtPolyRef; MAX_POLYS];
        let mut poly_count: i32 = 0;

        unsafe {
            let status = ffi::wrapper_dtNavMeshQuery_findPath(
                self.ptr.as_ptr(),
                start_ref,
                end_ref,
                start_pt.as_ptr(),
                end_pt.as_ptr(),
                filter.as_raw(),
                poly_path.as_mut_ptr(),
                &mut poly_count,
                MAX_POLYS as i32,
            );
            if status_failed(status) {
                return Err(DetourError::PathNotFound);
            }
        }

        // Convert to straight path
        let mut straight_path = vec![0.0f32; MAX_PATH * 3];
        let mut straight_flags = vec![0u8; MAX_PATH];
        let mut straight_refs = vec![0 as ffi::dtPolyRef; MAX_PATH];
        let mut straight_count: i32 = 0;

        unsafe {
            let status = ffi::wrapper_dtNavMeshQuery_findStraightPath(
                self.ptr.as_ptr(),
                start_pt.as_ptr(),
                end_pt.as_ptr(),
                poly_path.as_ptr(),
                poly_count,
                straight_path.as_mut_ptr(),
                straight_flags.as_mut_ptr(),
                straight_refs.as_mut_ptr(),
                &mut straight_count,
                MAX_PATH as i32,
                0, // options
            );
            if status_failed(status) {
                return Err(DetourError::StraightPathFailed);
            }
        }

        // Convert to Vec<Vec3>
        let path: Vec<Vec3> = (0..straight_count as usize)
            .map(|i| Vec3::new(
                straight_path[i * 3],
                straight_path[i * 3 + 1],
                straight_path[i * 3 + 2],
            ))
            .collect();

        Ok(PathResult {
            path,
            partial: status_detail(status, DT_PARTIAL_RESULT),
        })
    }

    /// Find random navigable point
    pub fn find_random_point(&self, filter: &QueryFilter) -> Result<Vec3, DetourError> {
        let mut random_ref: ffi::dtPolyRef = 0;
        let mut random_pt = [0.0f32; 3];

        unsafe {
            let status = ffi::wrapper_dtNavMeshQuery_findRandomPoint(
                self.ptr.as_ptr(),
                filter.as_raw(),
                &mut random_ref,
                random_pt.as_mut_ptr(),
            );
            if status_failed(status) {
                return Err(DetourError::from_status(status));
            }
        }

        Ok(Vec3::from_array(random_pt))
    }
}

// NavMeshQuery is NOT Send/Sync - internal state is not thread-safe
// impl !Send for NavMeshQuery {}
// impl !Sync for NavMeshQuery {}

impl Drop for NavMeshQuery {
    fn drop(&mut self) {
        unsafe {
            ffi::wrapper_dtFreeNavMeshQuery(self.ptr.as_ptr());
        }
    }
}
```

### 3.3 Query Pool Pattern

Since NavMeshQuery is not thread-safe, we use a pool pattern:

```rust
pub struct QueryPool {
    mesh: Arc<NavMesh>,
    pool: Mutex<Vec<NavMeshQuery>>,
    max_nodes: u32,
}

impl QueryPool {
    pub fn new(mesh: Arc<NavMesh>, initial_size: usize, max_nodes: u32) -> Self {
        let pool: Vec<NavMeshQuery> = (0..initial_size)
            .filter_map(|_| NavMeshQuery::new(mesh.clone(), max_nodes).ok())
            .collect();

        Self {
            mesh,
            pool: Mutex::new(pool),
            max_nodes,
        }
    }

    pub fn acquire(&self) -> PooledQuery<'_> {
        let query = {
            let mut pool = self.pool.lock().unwrap();
            pool.pop()
        }.unwrap_or_else(|| {
            NavMeshQuery::new(self.mesh.clone(), self.max_nodes)
                .expect("Failed to create query")
        });

        PooledQuery {
            query: Some(query),
            pool: self,
        }
    }
}

pub struct PooledQuery<'a> {
    query: Option<NavMeshQuery>,
    pool: &'a QueryPool,
}

impl<'a> std::ops::Deref for PooledQuery<'a> {
    type Target = NavMeshQuery;
    fn deref(&self) -> &Self::Target {
        self.query.as_ref().unwrap()
    }
}

impl<'a> Drop for PooledQuery<'a> {
    fn drop(&mut self) {
        if let Some(query) = self.query.take() {
            let mut pool = self.pool.pool.lock().unwrap();
            pool.push(query);
        }
    }
}
```

## 4. TrinityCore MMAP Format

### 4.1 File Structure

TrinityCore navigation meshes are stored in two file types:

**Map Metadata (.mmap)**: `{mapId:04}.mmap`
- Contains dtNavMeshParams structure (28 bytes)
- One file per map

**Tile Data (.mmtile)**: `{mapId:04}{x:02}{y:02}.mmtile`
- Contains TrinityCore header (20 bytes) + Detour tile data
- One file per grid tile (64x64 yard area)

### 4.2 Data Structures

```rust
/// TrinityCore mmap file header (map metadata)
#[repr(C, packed)]
#[derive(Debug, Clone, Copy)]
pub struct MmapNavMeshParams {
    pub orig: [f32; 3],       // World origin
    pub tile_width: f32,      // Tile width (usually 533.333)
    pub tile_height: f32,     // Tile height (usually 533.333)
    pub max_tiles: i32,       // Maximum tiles
    pub max_polys: i32,       // Maximum polygons per tile
}

/// TrinityCore mmtile file header
#[repr(C, packed)]
#[derive(Debug, Clone, Copy)]
pub struct MmapTileHeader {
    pub mmap_magic: u32,      // "MMAP" = 0x4D4D4150
    pub dt_version: u32,      // Detour version (7)
    pub mmap_version: u32,    // TC generator version (5-9)
    pub size: u32,            // Tile data size following header
    pub uses_liquids: u8,     // Has liquid data
    pub _padding: [u8; 3],    // Alignment padding
}

impl MmapTileHeader {
    pub const MAGIC: u32 = 0x4D4D4150; // "MMAP" in little-endian
    pub const DT_VERSION: u32 = 7;     // DT_NAVMESH_VERSION
    
    pub fn validate(&self) -> Result<(), MmapError> {
        if self.mmap_magic != Self::MAGIC {
            return Err(MmapError::InvalidMagic(self.mmap_magic));
        }
        if self.dt_version != Self::DT_VERSION {
            return Err(MmapError::UnsupportedDetourVersion(self.dt_version));
        }
        if self.mmap_version < 5 || self.mmap_version > 9 {
            return Err(MmapError::UnsupportedMmapVersion(self.mmap_version));
        }
        Ok(())
    }
}
```

### 4.3 Mmap Loader Implementation

```rust
pub struct MmapLoader {
    mmap_path: PathBuf,
    tile_cache: Mutex<HashMap<(u32, i32, i32), Vec<u8>>>,
}

impl MmapLoader {
    pub fn new(mmap_path: impl AsRef<Path>) -> Self {
        Self {
            mmap_path: mmap_path.as_ref().to_path_buf(),
            tile_cache: Mutex::new(HashMap::new()),
        }
    }

    /// Load map parameters from .mmap file
    pub fn load_map_params(&self, map_id: u32) -> Result<MmapNavMeshParams, MmapError> {
        let path = self.mmap_path.join(format!("{:04}.mmap", map_id));
        let data = std::fs::read(&path)?;

        if data.len() < std::mem::size_of::<MmapNavMeshParams>() {
            return Err(MmapError::FileTooSmall);
        }

        let params: MmapNavMeshParams = unsafe {
            std::ptr::read_unaligned(data.as_ptr() as *const _)
        };

        Ok(params)
    }

    /// Load tile data from .mmtile file
    pub fn load_tile(&self, map_id: u32, x: i32, y: i32) -> Result<Vec<u8>, MmapError> {
        // Check cache first
        {
            let cache = self.tile_cache.lock().unwrap();
            if let Some(data) = cache.get(&(map_id, x, y)) {
                return Ok(data.clone());
            }
        }

        let path = self.mmap_path.join(format!("{:04}{:02}{:02}.mmtile", map_id, x, y));
        let data = std::fs::read(&path)?;

        if data.len() < std::mem::size_of::<MmapTileHeader>() {
            return Err(MmapError::FileTooSmall);
        }

        // Parse and validate header
        let header: MmapTileHeader = unsafe {
            std::ptr::read_unaligned(data.as_ptr() as *const _)
        };
        header.validate()?;

        // Extract tile data (skip header)
        let tile_data_start = std::mem::size_of::<MmapTileHeader>();
        let tile_data_end = tile_data_start + header.size as usize;

        if data.len() < tile_data_end {
            return Err(MmapError::TruncatedTileData);
        }

        let tile_data = data[tile_data_start..tile_data_end].to_vec();

        // Cache the tile
        {
            let mut cache = self.tile_cache.lock().unwrap();
            cache.insert((map_id, x, y), tile_data.clone());
        }

        Ok(tile_data)
    }

    /// Check if tile exists
    pub fn tile_exists(&self, map_id: u32, x: i32, y: i32) -> bool {
        let path = self.mmap_path.join(format!("{:04}{:02}{:02}.mmtile", map_id, x, y));
        path.exists()
    }

    /// Get tile coordinates for world position
    pub fn get_tile_coords(params: &MmapNavMeshParams, pos: Vec3) -> (i32, i32) {
        let x = ((pos.x - params.orig[0]) / params.tile_width) as i32;
        let y = ((pos.z - params.orig[2]) / params.tile_height) as i32;
        (x, y)
    }
}
```

## 5. HTTP Service Architecture

### 5.1 Application State

```rust
pub struct AppState {
    pub mmap_loader: Arc<MmapLoader>,
    pub navmeshes: DashMap<u32, Arc<NavMesh>>,
    pub query_pools: DashMap<u32, QueryPool>,
    pub config: Config,
    pub pathfinding_semaphore: Arc<Semaphore>,
}

impl AppState {
    pub async fn get_or_load_navmesh(&self, map_id: u32) -> Result<Arc<NavMesh>, ApiError> {
        // Check if already loaded
        if let Some(mesh) = self.navmeshes.get(&map_id) {
            return Ok(mesh.clone());
        }

        // Load in background
        let params = self.mmap_loader.load_map_params(map_id)?;
        let mesh = NavMesh::new(&params.into())?;
        let mesh = Arc::new(mesh);

        self.navmeshes.insert(map_id, mesh.clone());
        self.query_pools.insert(
            map_id, 
            QueryPool::new(mesh.clone(), self.config.query_pool_size, 2048)
        );

        Ok(mesh)
    }

    pub async fn ensure_tiles_loaded(
        &self,
        map_id: u32,
        start: Vec3,
        end: Vec3,
    ) -> Result<(), ApiError> {
        let mesh = self.get_or_load_navmesh(map_id).await?;
        let params = self.mmap_loader.load_map_params(map_id)?;

        // Calculate tiles needed
        let start_tile = MmapLoader::get_tile_coords(&params, start);
        let end_tile = MmapLoader::get_tile_coords(&params, end);

        let min_x = start_tile.0.min(end_tile.0);
        let max_x = start_tile.0.max(end_tile.0);
        let min_y = start_tile.1.min(end_tile.1);
        let max_y = start_tile.1.max(end_tile.1);

        // Load tiles in range
        for x in min_x..=max_x {
            for y in min_y..=max_y {
                if self.mmap_loader.tile_exists(map_id, x, y) {
                    let tile_data = self.mmap_loader.load_tile(map_id, x, y)?;
                    mesh.add_tile(TileData::Owned(tile_data.into_boxed_slice()), None)?;
                }
            }
        }

        Ok(())
    }
}
```

### 5.2 Route Handlers

```rust
// GET /api/v1/path
pub async fn find_path(
    State(state): State<Arc<AppState>>,
    Query(params): Query<PathParams>,
) -> Result<Json<PathResponse>, ApiError> {
    let _permit = state.pathfinding_semaphore.acquire().await?;
    
    let start = Vec3::new(params.start_x, params.start_y, params.start_z);
    let end = Vec3::new(params.end_x, params.end_y, params.end_z);

    // Ensure tiles are loaded
    state.ensure_tiles_loaded(params.map_id, start, end).await?;

    // Get query from pool
    let pool = state.query_pools.get(&params.map_id)
        .ok_or(ApiError::MapNotLoaded)?;
    let query = pool.acquire();

    // Find path (blocking, so spawn_blocking)
    let filter = QueryFilter::default();
    let smoothing = params.smoothing.as_deref();
    
    let start_time = Instant::now();
    
    let result = tokio::task::spawn_blocking(move || {
        query.find_path(start, end, &filter)
    }).await??;

    // Apply smoothing
    let path = match smoothing {
        Some("chaikin") => smooth_chaikin(&result.path, 2),
        Some("catmull_rom") => smooth_catmull_rom(&result.path, 10),
        Some("bezier") => smooth_bezier(&result.path),
        _ => result.path,
    };

    let distance = calculate_path_distance(&path);
    let compute_time_ms = start_time.elapsed().as_secs_f64() * 1000.0;

    Ok(Json(PathResponse {
        success: true,
        path: path.into_iter().map(|v| [v.x, v.y, v.z]).collect(),
        distance,
        compute_time_ms,
        partial: result.partial,
        error: None,
    }))
}
```

## 6. Path Smoothing Algorithms

### 6.1 Chaikin Curve Subdivision

Iteratively cuts corners to create smoother curves:

```rust
pub fn smooth_chaikin(path: &[Vec3], iterations: usize) -> Vec<Vec3> {
    if path.len() < 3 {
        return path.to_vec();
    }

    let mut current = path.to_vec();

    for _ in 0..iterations {
        let mut next = Vec::with_capacity(current.len() * 2);
        next.push(current[0]); // Keep start point

        for i in 0..current.len() - 1 {
            let p0 = current[i];
            let p1 = current[i + 1];

            // Q = 3/4 * P0 + 1/4 * P1
            let q = Vec3::new(
                0.75 * p0.x + 0.25 * p1.x,
                0.75 * p0.y + 0.25 * p1.y,
                0.75 * p0.z + 0.25 * p1.z,
            );

            // R = 1/4 * P0 + 3/4 * P1
            let r = Vec3::new(
                0.25 * p0.x + 0.75 * p1.x,
                0.25 * p0.y + 0.75 * p1.y,
                0.25 * p0.z + 0.75 * p1.z,
            );

            next.push(q);
            next.push(r);
        }

        next.push(*current.last().unwrap()); // Keep end point
        current = next;
    }

    current
}
```

### 6.2 Catmull-Rom Spline

Smooth interpolation through control points:

```rust
pub fn smooth_catmull_rom(path: &[Vec3], segments_per_span: usize) -> Vec<Vec3> {
    if path.len() < 4 {
        return path.to_vec();
    }

    let mut result = Vec::new();

    for i in 0..path.len() - 1 {
        let p0 = if i == 0 { path[0] } else { path[i - 1] };
        let p1 = path[i];
        let p2 = path[i + 1];
        let p3 = if i + 2 >= path.len() { path[path.len() - 1] } else { path[i + 2] };

        for j in 0..segments_per_span {
            let t = j as f32 / segments_per_span as f32;
            let point = catmull_rom_point(p0, p1, p2, p3, t);
            result.push(point);
        }
    }

    result.push(*path.last().unwrap());
    result
}

fn catmull_rom_point(p0: Vec3, p1: Vec3, p2: Vec3, p3: Vec3, t: f32) -> Vec3 {
    let t2 = t * t;
    let t3 = t2 * t;

    Vec3::new(
        0.5 * ((2.0 * p1.x) +
               (-p0.x + p2.x) * t +
               (2.0 * p0.x - 5.0 * p1.x + 4.0 * p2.x - p3.x) * t2 +
               (-p0.x + 3.0 * p1.x - 3.0 * p2.x + p3.x) * t3),
        0.5 * ((2.0 * p1.y) +
               (-p0.y + p2.y) * t +
               (2.0 * p0.y - 5.0 * p1.y + 4.0 * p2.y - p3.y) * t2 +
               (-p0.y + 3.0 * p1.y - 3.0 * p2.y + p3.y) * t3),
        0.5 * ((2.0 * p1.z) +
               (-p0.z + p2.z) * t +
               (2.0 * p0.z - 5.0 * p1.z + 4.0 * p2.z - p3.z) * t2 +
               (-p0.z + 3.0 * p1.z - 3.0 * p2.z + p3.z) * t3),
    )
}
```

## 7. Thread Safety Model

### 7.1 Component Thread Safety

| Component | Thread Safety | Implementation |
|-----------|--------------|----------------|
| NavMesh | Send + Sync | Read-only after init |
| NavMeshQuery | NOT Send/Sync | Query pool pattern |
| QueryFilter | Send + Sync | Immutable configuration |
| MmapLoader | Send + Sync | Mutex-protected cache |
| AppState | Send + Sync | DashMap + Arc |

### 7.2 Concurrency Design

```
┌─────────────────────────────────────────────────────────────────┐
│                     Tokio Runtime (multi-threaded)              │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │                    Axum Request Handlers                   │ │
│  │  (async, multiple concurrent requests)                     │ │
│  └───────────────────────────────────────────────────────────┘ │
│                              │                                  │
│                              ▼                                  │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │                spawn_blocking() for pathfinding           │ │

│  └───────────────────────────────────────────────────────────┘ │
│                              │                                  │
│                              ▼                                  │
│  ┌───────────────────────────────────────────────────────────┐ │
```

### 8.2 API Error Response

```rust
impl IntoResponse for ApiError {
    fn into_response(self) -> Response {
        let (status, message) = match &self {
            ApiError::Detour(e) => (StatusCode::INTERNAL_SERVER_ERROR, e.to_string()),
            ApiError::Mmap(e) => (StatusCode::NOT_FOUND, e.to_string()),
            ApiError::MapNotLoaded(id) => (StatusCode::NOT_FOUND, format!("Map {} not loaded", id)),
            ApiError::InvalidParams => (StatusCode::BAD_REQUEST, "Invalid parameters".to_string()),
        };

        let body = Json(PathResponse {
            success: false,
            path: vec![],
            distance: 0.0,
            compute_time_ms: 0.0,
            partial: false,
            error: Some(message),
        });

        (status, body).into_response()
    }
}
```
