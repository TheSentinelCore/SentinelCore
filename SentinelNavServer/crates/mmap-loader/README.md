# mmap-loader

Loads `.mmap` (map metadata) and `.mmtile` (navmesh tile) files into Detour navmeshes.

## Supported formats

This crate supports mmtile files generated by **two different WoW server emulators**. The raw Detour tile data (`DT_NAVMESH_VERSION = 7`) is identical between both — only the file header differs.

### CMaNGOS / MaNGOS (original format)

| Field | Type | Bytes |
|-------|------|-------|
| `mmap_magic` | u32 | 0-3 |
| `dt_version` | u32 | 4-7 |
| `mmap_version` | u32 | 8-11 |
| `size` | u32 | 12-15 |
| `uses_liquids` | u8 | 16 |
| `_padding` | [u8; 3] | 17-19 |
| **Detour tile data** | — | **20+** |

- **Header size**: 20 bytes
- **MMAP_VERSION**: 4-9 (varies by fork)
- **Generator config**: hardcoded, not configurable per-map

### AzerothCore / TrinityCore

| Field | Type | Bytes |
|-------|------|-------|
| `mmap_magic` | u32 | 0-3 |
| `dt_version` | u32 | 4-7 |
| `mmap_version` | u32 | 8-11 |
| `size` | u32 | 12-15 |
| `uses_liquids` | u8 | 16 |
| `_padding` | [u8; 3] | 17-19 |
| `recast_config` | MmapTileRecastConfig | 20-55 |
| **Detour tile data** | — | **56+** |

- **Header size**: 56 bytes (20 base + 36 RecastConfig)
- **MMAP_VERSION**: 19
- **Generator config**: YAML-based, configurable per-map and per-tile

#### MmapTileRecastConfig (36 bytes)

| Field | Type | Description |
|-------|------|-------------|
| `walkable_slope_angle` | f32 | Max walkable slope in degrees |
| `walkable_radius` | u8 | Agent radius in cell units |
| `walkable_height` | u8 | Agent height in cell units |
| `walkable_climb` | u8 | Max step height in cell units |
| `_padding0` | u8 | Alignment padding |
| `vertex_per_map_edge` | u32 | Grid resolution |
| `vertex_per_tile_edge` | u32 | Tile chunk resolution |
| `tiles_per_map_edge` | u32 | Number of tiles per edge |
| `base_unit_dim` | f32 | Cell size in world units |
| `cell_size_horizontal` | f32 | Horizontal cell size |
| `cell_size_vertical` | f32 | Vertical cell size |
| `max_simplification_error` | f32 | Polygon simplification tolerance |

## Why AzerothCore produces better mmaps

| Aspect | CMaNGOS/MaNGOS | AzerothCore |
|--------|----------------|-------------|
| Grid resolution | Fixed (~2000) | Configurable (up to 3000+) |
| Simplification error | Fixed (~1.8) | Configurable (down to 0.8) |
| Agent radius | Fixed (~2) | Configurable per-map |
| Per-tile overrides | No | Yes (via YAML) |
| Recast config in header | No | Yes (enables verification) |

### Recommended ultra-quality settings (mmaps-config.yaml)

```yaml
meshSettings:
  walkableSlopeAngle: 60
  walkableHeight: 6
  walkableClimb: 6
  walkableRadius: 3          # default 2 — keeps NPCs away from walls
  verticesPerMapEdge: 3000   # default 2000 — maximum mesh resolution
  verticesPerTileEdge: 80
  maxSimplificationError: 0.8 # default 1.8 — maximum polygon accuracy
```

## File patterns

- Map metadata: `{mapId:03}.mmap` (e.g., `000.mmap`)
- Tile data: `{mapId:03}{x:02}{y:02}.mmtile` (e.g., `0002337.mmtile`)

## Version compatibility

| Source | MMAP_VERSION | Accepted? |
|--------|-------------|-----------|
| MaNGOS | 4 | Yes |
| CMaNGOS | 5-9 | Yes |
| TrinityCore | 10-15 | Yes |
| AzerothCore | 19 | Yes |
